## 五、踩过的坑（重要，别再踩）

### 1. 数据盘扩容后不生效
控制台扩到 250G 后，`df` 仍显示 150G。原因：`/root/autodl-tmp` 是宿主机 14T 阵列上的
**子目录 bind mount**，容量由 **xfs project quota（prjquota, projid=11223）** 控制。
- `xfs_growfs` 不适用（只能扩整块文件系统，且容器里报 "not a mounted XFS filesystem"）
- 解决办法：**关机再开机**，由平台重新下发配额（重启后即变为 250G）

### 2. ModelScope 下载的 Wan 模型是原始格式，diffusers 加载不了
`Wan-AI/Wan2.2-*` 下载下来是权重平铺的原始格式（**没有 `model_index.json`**），
而流水线用 `diffusers.WanImageToVideoPipeline`，必须标准 diffusers 目录结构。
- 解决：改下载官方 **`-Diffusers`** 变体（`Wan-AI/Wan2.2-TI2V-5B-Diffusers` 等）
- 曾尝试用官方 `convert_wan_to_diffusers.py` 本地转换，但脚本走 `snapshot_download` 从 HF 下载，
  而 **HF 直连不通**；构造 HF 离线缓存也被新版 huggingface_hub 拒绝 → 放弃转换
- A14B 转换还额外受限于空间（需"原始 118G + 输出 117G"并存），故**删除原始版**改下载

### 3. HF 官方不可达
`huggingface.co` 连不上。可用替代：
- **ModelScope**（首选，国内快）：`snapshot_download(id, cache_dir=...)`
- **hf-mirror**：`HF_ENDPOINT=https://hf-mirror.com`（已写入 .env 兜底）
- GitHub raw / github.com 可达

### 4. SDXL 只下 fp16
fp32 与 fp16 体积/显存差 2 倍。纯推理 fp16 画质几乎无差别、速度快 1.5–3 倍。
已用 `ignore_patterns` 排除 fp32，并删除已混入的 fp32 文件，SDXL 从 9.9G 降到 **6.6G**。

### 5. 无卡开机时看不到 GPU
`nvidia-smi` 权限被拒、`/dev/nvidia*` 不存在、`torch.cuda.is_available()` 为 False —— 属正常，
装环境/下模型不需要 GPU，无卡模式（≈0.1 元/时）做这些最省钱。

### 6. SSH 重连会被限流
短时间内重连 AutoDL 网关会失败，工具已加退避重试。另外 **`pkill -f <关键字>` 会误杀自己的
shell**（命令行匹配到自身），要用 `ps -eo pid,comm,args` 精确匹配 python 进程再 kill。

## 六、明天开机后的操作步骤

### 第 1 步：开机
控制台 **关机 → 开机，选择 GPU 计费（5090 / 32G）**。
开机后 **SSH 端口会变**，复制新的登录指令（形如 `ssh -p xxxxx root@connect.bjb1.seetacloud.com`）。

### 第 2 步：环境体检
```bash
nvidia-smi --query-gpu=name,memory.total --format=csv,noheader
/root/miniconda3/bin/python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
cd /root/autodrama && python -m autodrama status -p demo
```

### 第 3 步：跑 SDXL 出首帧（先验证出图与 IP-Adapter）
```bash
cd /root/autodrama
python -m autodrama init --name demo --idea "车祸后，她发现丈夫的记忆里住着另一个女人" --episodes 3
python -m autodrama run -p demo --ep 1 --yes
```
观察日志里是否出现 `[info] IP-Adapter 已加载（角色一致性开启）`。

### 第 4 步：5B / A14B 对比（同一镜头）
改 `.env` 的 `AUTODRAMA_VIDEO_MODEL` 分别跑，记录耗时与画质：
- 先跑 5B（显存友好、速度快）
- 再跑 A14B（质量优先）—— 若 OOM，worker 会自动三级降档（原分辨率 → 0.75 → 0.6 且帧数减半）

### 第 5 步（可选）：启用配音
装 CosyVoice 依赖（Matcha-TTS、onnxruntime、WeTextProcessing 等），
测试一条语音出声后，把 `AUTODRAMA_TTS` 从 `mock` 改成 `worker`。
